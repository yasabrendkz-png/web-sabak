# 📘 WEB бағдарламалау — электрондық кітап

С.Сейфуллин атындағы Қазақ агротехникалық зерттеу университеті · «WEB бағдарламалау» пәні
Оқытушы: Найзағараева А.А. · Астана, 2026

Пәннің 4 материалы бір интерактивті кітапқа біріктірілген: силлабус, 15 дәріс, 15 СӨЖ тапсырмасы және бақылау сұрақтары.

## Мүмкіндіктері
- 📕 Мұқаба, парақ аудару анимациясы мен дыбысы
- ☰ Мазмұны, қызыл бетбелгі-лента және түсті қойындылар
- 🔍 Бүкіл кітап бойынша іздеу
- 🔊 Дауыстап оқу
- 🔖 Жеке бетбелгілер, соңғы оқыған беттен жалғастыру
- ❓ Бақылау сұрақтары: «Білемін» белгісі, прогресс, «Өзіңді тексер» режимі
- 🌙 Түнгі режим, әріп өлшемі, телефонға бейімделген

## Ашу
- **Онлайн:** GitHub Pages сілтемесі (Settings → Pages).
- **Компьютерде:** `index.html` файлын браузерде ашу жеткілікті.

## Құрылымы
```
index.html        # дайын кітап (дизайн мен код осының ішінде)
syllabus.pdf      # пәннің жұмыс бағдарламасы
lectures.pdf      # дәрістер жинағы
soj.pdf           # СӨЖ тапсырмалары
control.pdf       # бақылау материалдары
CHANGELOG.md      # нұсқалар тарихы
```

## Жаңарту
Web стандарттары мен технологиялары үнемі жаңарады, сондықтан кітап та жаңартылып отырады.
Әр жаңа нұсқа `CHANGELOG.md`-ге жазылып, GitHub-қа Commit ретінде жіберіледі — өзгерістер тарихын
**Commits** бөлімінен көруге болады.
